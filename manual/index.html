OverLIVE 体験版説明書 v0.6.0

    OverLIVE の使い方

    Apex Legends（PC版）のゲーム画面に、かわいい枠を重ねるアプリです。HP・シールドの変化に合わせて、キャラの表情と枠の色が動きます。

    安全についてゲームの画面を「OBS と同じ画面キャプチャ」で見て、HP・シールドの見た目に反応するだけです。ゲームへのコード注入・メモリの読み書き・入力の操作は一切しません。

    困ったときはここから

    枠が表示されないゲームの上に何も出ない 反応しない被弾しても色が変わらない 位置がずれるゲームの表示と合わない 重い・カクつくfps・G-SYNC 配信に映らないOBS のゲームキャプチャ キーが効かないAlt+H・Alt+M

    右上の検索欄に言葉を入れると、その言葉が出てくる所だけを表示します。メニューの「？」からも、そのページの説明にすぐ飛べます。

    1起動するまで

    1. zip を展開する
      ダウンロードした zip を右クリック →「すべて展開」。デスクトップやドキュメントなど、好きな場所に置いてください。
      zip の中から直接起動すると、設定が保存されないことがあります。
    2. Apex の画面モードを「ボーダーレスウィンドウ」にする
      Apex の「設定」→「ビデオ」→「表示モード」を ボーダーレスウィンドウ に。フルスクリーンだと、どのオーバーレイも表示されません。HUD のサイズ（ゲームの設定）は既定のままにしてください。
    3. 「OverLIVE を起動」をダブルクリック（「app」フォルダの中はアプリ本体です。開いたり中身を動かしたりしないでください）
      初めてのときは Windows の「PC を保護しました」が出ることがあります →「詳細情報」→「実行」で起動できます（個人制作のため、ソフトに会社の署名がないことが理由です）。
    4. 「HUD が正しく見えていますか？」で「見えている（続ける）」を押す
      画面に枠が出て、ゲームやデスクトップが透けて見えていれば OK です。押さないと 20 秒で自動で終了します（万一、画面がふさがったときの安全装置）。一度押せば、次からは出ません（アップデート後は1回だけ出ます）。
    メモアプリが動いている間は、画面右下のタスクトレイ（通知領域）にアイコンが出ます。右クリックで「メニュー」「説明書」「HUD 表示/非表示」「終了」が選べます。

    2基本の操作（キー）

    キーできること
    Alt + H（または Insert）HUD の表示 ON / OFF
    Alt + Mメニューを開く／閉じる（キャラの切り替え・表示する項目・設定）
    Alt + B背景画像の調整モード（画像が入る枠に点線が出ます）
    Ctrl + Shift + F12アプリを終了（タスクトレイのアイコンを右クリック →「終了」でも終了できます）

    画面の右下に、HUD の ON/OFF とメニューの OPEN/CLOSE が小さく表示されます。体験版では「のこり ◯分」も表示されます。

    注意メニューは、試合の外で開くのがおすすめです。メニューを開くと、マウスやキーの操作がメニューに移ります（ゲームに戻るときはゲームをクリック）。メニューを × で閉じても HUD は動いたままです。

    キーを変えたいときは 「キーが効かない・変えたい」 を見てください。

    3何に反応するか

    ゲーム画面の変化キャラの表情枠
    HP かシールドが減る被弾赤く点滅
    シールドが 0 になるシールド破壊紫
    HP が 35% 以下ピンチ（続く）—
    HP・シールドが増えた（回復アイテムを使い終わったとき）回復（少しのあいだ）緑
    HP・シールドが少しずつ増えている（スキルなどで回復中）回復（増えている間ずっと）緑
    HP が満タンになる全回復（ハートのキラキラ）—
    HP が 0 になるダウン（続く）ダウン中の枠に切り替え
    味方の HP・シールドが減る／0／増える—味方の枠が赤／紫／緑
    アーマーの段数が変わる—シールドの窓が増減
    アイテム・戦術スキルの表示が出る／消える—水色の窓が開く／閉じる
    マップやメニューを開いてゲームの HUD が消える—枠も一緒に隠れる
    ゲーム画面の変化キャラの表情枠
    HP かシールドが減る被弾赤く点滅
    シールドが 0 になる被弾紫
    HP・シールドが増えた（回復アイテムを使い終わったとき など）回復緑
    マップやメニューを開いてゲームの HUD が消える—枠も一緒に隠れる
    回復のタイミングApex の回復アイテム（シリンジ・医療キット・セル・バッテリー）は、使い終わった瞬間にゲージが増えます。HUD はゲージが増えたのを見て反応するので、緑に光るのは「使い終わったとき」です（使っている途中は反応しません）。スキルなどで少しずつ回復するときは、増えている間ずっと緑になります。

    キル・優勝・アビリティの状態は、まだ画面から読んでいません。

    メモ射撃訓練場などで方位計が出ていないときは、ミニマップ・方位の枠も隠れます。故障ではありません。

    4メニューの見方

    Alt + M で開きます。上のタブで画面を切り替えます。設定は自動で保存され、次に起動したときも同じになります。上の「？ 使い方」でこの説明書が開きます。

    キャラ

    • キャラを選ぶ：押すとすぐ切り替わります。ヨシュアと 7 人の仲間、全部で 8 人です（体験版のキャラ AQUA は、製品版には入っていません）。
    • キャラ：体験版は AQUA だけです。
    • キャラなし（枠だけ）：キャラを出さずに枠だけを表示します。自分の VTuber モデルを横に出す配信者さんなどに。
    • 枠に表示する名前：入れて「反映」。空欄で「反映」すると名前を表示しません（背景画像のロゴを名前の位置に見せたいときなど）。「キャラの名前に戻す」で元に戻せます。
    • 自分の画像を使う（マイキャラ）：マイキャラの使い方 を見てください。

    枠の色

    • 飾りあり：キャラ専用の枠（猫耳・リボンなど、キャラごとの飾り付き）。
    • 飾りなし：飾りのないシンプルな枠。色はキャラに近い色になります。
    • 好きな色にする：10 色から選べます。どのキャラ・マイキャラとも組み合わせられます。

    表示

    チェックを外した項目は表示しません（すぐ反映）。

    • キャラ画像・名前・自分の体力枠・味方の枠・ミニマップ枠・方位・アイテム・戦術スキル・ウルト・武器
    • エフェクト：光の流れ・キラキラ。OFF にすると少し軽くなります。
    • 待機モーション：キャラがふわっと動く動き。
    • 使っていない窓を閉じる：アイテムなどが無いとき、窓を枠でふさぎます。
    • チャット翻訳（試験中）：英語のチャットに、ぎこちない日本語を添えます（ネットは使いません）。

    設定

    • 読み取り ON/OFF：ゲーム画面の HP・シールドを読むかどうか。ふだんは ON。
    • 読み取り範囲を表示：どこを読んでいるかを点線で表示します（位置がずれるときの確認用）。
    • 配信に出す（OBS）：配信に HUD を出す を見てください。
    • デモ再生：ゲームを起動していなくても、動きを確認できます。
    • 診断ログ・ログフォルダ：うまく反応しないときの調査用。お問い合わせ のときに使います。
    • 性能表示：HUD の描画の速さを表示します。

    5マイキャラ（自分の画像を使う）カスタム版

    1. フォルダを開く
      メニュー「キャラ」→「自分の画像を使う」→「フォルダを開く」。場所は ドキュメント\OverLIVE\マイキャラ です。
    2. 画像を置く
      いちばん簡単なのは、画像を 1 枚 置くだけ。全部の表情にその画像を使います。
    3. 「再読み込み」を押す
      キャラの一覧に「マイキャラ」の印つきで出てきます。押すと切り替わります。

    表情を出し分ける

    フォルダを作り（フォルダ名がキャラ名になります）、中に次の名前で画像を置きます。足りない表情は「通常」で代わりに表示します。

    ファイル名出るとき
    通常.png（必須）いつもの顔
    被弾.pngダメージを受けたとき
    シールド破壊.pngシールドが割れたとき
    HP低下.png体力が少ないとき（ピンチ）
    回復.png（回復中.png も可）回復したとき
    全回復.png全回復したとき
    キル.pngキルしたとき（今は自動では出ません）
    ダウン.pngダウンしたとき

    英語の名前（normal hit shield_break hp_low healing full_heal kill knockdown）でも OK です。

    きれいに見せるコツ

    • PNG / JPG が使えます。背景が透明な PNG がおすすめです（背景の自動削除はしません）。
    • 正方形に近い「顔〜胸元」の画像がきれいに収まります。画像は横 200：縦 185 の比率に、上寄せ・左右中央で自動で切り抜きます。
    • 表情ごとの画像は、同じ大きさ・同じ位置で描くと、切り替わったときにずれません。
    使える画像自分で描いた絵、または権利者から「ゲーム画面での表示・配信での使用・加工」の許可をもらった絵だけです。くわしくは 画像の権利のルール。

    6枠の背景に好きな画像を入れるカスタム版

    1. 「背景」タブ →「画像を選ぶ」
      PNG・JPG・WebP が使えます。画像はアプリの設定フォルダにコピーして使うので、元の画像を動かしても消えません。
    2. プレビューで位置を合わせる
      プレビューを ドラッグで移動、マウスホイールで拡大・縮小。スライダーでも調整できます。
    3. 濃さ・明るさ・ぼかしを整える
      濃さは 0〜100（初めは 60）。文字やロゴを見せたいときは濃いめ、柄だけなら薄めがおすすめです。
    4. ゲーム画面で確認する
      Alt + B で調整モード。画像が入る枠に点線が出ます。ゲームを見ながらメニューで直せます。
    • 画像が入るのは枠のパネル（濃い色の部分）だけです。HP・シールドなど、ゲームの表示が見える窓はふさぎません。
    • 今の枠のデザインでは、パネルがあるのは主に 自分の体力枠 です（味方・アイテムなどは線だけの枠なので、画像はほとんど出ません）。
    • 「画像を入れる枠」で、入れる枠を選べます。
    • 枠の色やキャラを変えると、画像の入る形も自動でその枠に合わせます。
    • 「位置・濃さを元に戻す」で初めの状態に、「画像を外す」で画像なしに戻ります。
    ロゴを名前の位置に見せたいとき「画像を入れる枠」を「自分の体力枠」だけにして、大きさ・位置をロゴが名前の所に来るように合わせます。そのあと「キャラ」タブで名前を空欄にして「反映」。

    7配信に HUD を出す（OBS・TikTok LIVE Studio）

    OBS の使い方によって 2 通りあります。

    A. OBS で「画面キャプチャ」を使っている

    何もしなくても HUD が映ります。画面に見えているものをそのまま取るためです（デスクトップの通知なども映るので注意）。

    B. OBS で「ゲームキャプチャ」を使っている（Apex の配信で多い）

    ゲームキャプチャはゲームの映像だけを取るので、そのままでは HUD は映りません。「ブラウザ」ソースを 1 つ足すと映ります。

    1. URL をコピー
      メニュー「設定」→「配信に出す（OBS）」の「コピー」。URL は http://127.0.0.1:47812/obs です。
    2. OBS でブラウザソースを追加
      「ソース」の ＋ →「ブラウザ」→ 名前をつけて OK。
    3. 設定を入れる
      URL：コピーした URL ／ 幅・高さ：ゲームの解像度（例 1920 と 1080）／「ソースが表示されていないときにシャットダウン」と「シーンがアクティブになったときブラウザの表示を更新」は オフ。
    4. 並びと大きさを合わせる
      ブラウザソースを「ゲームキャプチャ」より 上 に置き、右クリック →「変換」→「画面に合わせる」。ゲームキャプチャと同じ大きさ・位置にします。
    5. 確認
      メニューに「OBS：つながっています」と出れば OK。被弾すると配信の画面でも枠が赤くなります。

    自分の画面には出さず、配信にだけ出す

    「自分の画面にも出す」のチェックを外すと、自分のゲーム画面には何も出さず、配信（ブラウザソース）にだけ HUD を出せます。画面の読み取りは続けるので、配信の HUD はちゃんと反応します。

    メモ通信はこのパソコンの中だけで行い、外には出ません。アプリを起動し直すと、OBS 側も自動で読み込み直します。読み取り範囲の点線など、確認用の表示は配信には出ません。

    TikTok LIVE Studio などで使う（OBS を使わないとき）

    TikTok LIVE Studio のように「ブラウザ」ソースに http:// のアドレスを入れられない配信アプリでは、「配信用の窓」を使います。ゲーム画面と HUD を重ねた窓をアプリが出すので、配信アプリでその窓を取り込むだけで HUD つきのゲーム画面になります（OBS は要りません）。

    1. 配信用の窓を開く
      メニュー「設定」→「TikTok LIVE Studio など（OBS を使わないとき）」の「配信用の窓を開く」。Apex が起動していれば、黒い窓にゲーム画面と HUD が映ります（ゲームを起動する前に開いても、起動すると自動で映ります）。
    2. 配信アプリで取り込む
      TikTok LIVE Studio なら「ソースを追加」→「ウィンドウキャプチャ」→ 一覧から 「【配信用の窓】」と書かれたものを選びます。縦配信なら、画面の真ん中に横幅いっぱいで置きます。
    3. ゲームの音を足す
      配信用の窓には音が入りません。配信アプリでゲーム（r5apex_dx12.exe）のソースを足し、映像は非表示（目のマーク）にしておくと、音だけ拾えます。
    メモ配信用の窓は 最小化しない でください（映像が止まります）。ゲームの後ろに置いておけば大丈夫です。窓はドラッグで動かせます。閉じるときはメニューの同じボタン（「配信用の窓を閉じる」）を押します。
    ゲームの手前に重ねて置くと、HUD の画面の読み取りがうまく動かないことがあります。
    うまく映らないとき窓が黒いままのときは、Apex の表示モードを「ボーダーレスウィンドウ」にしてみてください。カクつく場合は、OBS を使える環境なら上の「B」の方法のほうがなめらかです。

    コメントを画面に出す（わんコメ）試作

    コメントビューア わんコメ で受け取った YouTube・Twitch・TikTok のコメントを、ゲーム画面の右上寄りに HUD と同じデザインで出せます。別のモニターやスマホを見なくても、ゲームをしながらコメントが読めます。

    1. わんコメを用意する
      わんコメ（無料）を入れて起動し、配信の URL（チャンネル）を登録しておきます。わんコメは普通に起動してください（管理者として実行しなくて大丈夫です）。
    2. コメントを出す
      メニュー「設定」→「コメントを画面に出す（わんコメ）」の「コメントを出す」にチェック。「わんコメ：つながっています」と出れば準備完了です。
    3. 試す
      「テストコメントを送る」を押すと、わんコメのテスト機能から1件流れてきて、コメント欄が出ます。
    • 新しいコメントほど下に出て、最新の 3 件まで出ます。コメントは 25 秒で消え、全部消えるとコメント欄も消えます。
    • ギフト・スーパーチャットはピンクの帯で目立たせます。
    • コメントは 自分の画面・配信用の窓 の両方に出ます。「自分の画面にも出す」を外すと、配信にだけ出ます（HUD の設定とは別に選べます）。
    • OBS で出すときは、メニューのコメントの欄の「コピー」で URL（http://127.0.0.1:47812/renderer/comments.html?full=1）をコピーし、HUD とは別のブラウザソースに貼ります（幅・高さはゲームと同じ。HUD のブラウザソースの上に置く）。OBS の中で大きさ・位置を自由に変えられます。
    メモTikTok のコメントは、わんコメでは「一部対応」の扱いです。取れない場合があります。コメントの受け取りはこのパソコンの中だけで行います。この機能は わんコメ（OneComme） の API を使っています。

    録画（NVIDIA のインスタントリプレイなど）

    画面全体を録画するソフトには、そのまま HUD が映ります。切り抜きやショート動画づくりにも使えます。

    8困ったとき

    まずはアプリの「かんたん診断」：メニュー（Alt + M）→「設定」→「かんたん診断」。よくある原因をアプリが確かめて、直し方をその場で出します。試合中に押すといちばん正確です。

    枠が表示されない
    • Apex の表示モードが ボーダーレスウィンドウ か確認してください（フルスクリーンでは表示されません）。
    • 右下の表示が「OFF」なら、Alt + H で ON にします。
    • アプリが動いているか、タスクトレイのアイコンで確認します。
    • マップ・インベントリ・メニューを開いている間や、ゲームの外では、枠も自動で隠れます（故障ではありません）。メニューの「設定」に「ゲームの HUD：検出中」と出ていれば読めています。
    • 「自分の画面にも出す」のチェックが外れていないか確認します（外すと配信にだけ出ます）。
    • 複数のモニターを使っている場合は、ゲームを メインのモニター に出してください。
    画面が黒くなった・ふさがった

    Ctrl + Shift + F12 で終了、またはタスクトレイのアイコンを右クリック →「終了」を選んでください。起動時の「見えていますか？」を押さなければ 20 秒で自動で終了します。続くときは お問い合わせ ください。

    被弾しても反応しない・反応がおかしい
    • メニュー「設定」の「読み取り」が ON か確認します。
    • Apex の HUD のサイズを既定 に戻してください。HUD の大きさや色の設定を変えていると、正しく読めないことがあります。
    • 「読み取り範囲を表示」で、点線が HP・シールドのバーに重なっているか確認します。
    • 直らないときは「かんたん診断」を試してから、お問い合わせ ください。
    枠の位置がゲームの表示とずれる
    • Apex の HUD のサイズを既定にしてください。
    • HUD は画面の高さに合わせて自動で拡大・縮小します。よく使われる解像度（1920×1080、2560×1440、3840×2160、2560×1080、3440×1440）に対応しています。
    • 引き伸ばし（ストレッチ）解像度には対応していません（フルスクリーン専用の設定のため）。
    • ずれ方のスクリーンショットを送ってもらえれば、調整します。
    重い・fps が下がる・G-SYNC が効かない気がする
    • メニュー「表示」で「エフェクト」「待機モーション」を OFF にすると軽くなります。
    • NVIDIA の G-SYNC（可変リフレッシュレート）は、ボーダーレスのゲームの上に常に手前の窓があると効かなくなることがある、と報告されています（このアプリに限らず、オーバーレイ全般の Windows の仕組みによるもの）。気になるときは HUD を OFF にして比べてください。
    • 配信をしている人は「自分の画面にも出す」を外して配信にだけ出すと、自分の画面には窓が出ないので、この影響もありません。
    • メモリは 16GB 以上をおすすめします。
    配信（OBS）に HUD が映らない
    • OBS の「ゲームキャプチャ」では映りません。ブラウザソース を足してください。
    • ブラウザソースが真っ白・何も出ないときは、アプリが起動しているか、URL が http://127.0.0.1:47812/obs か確認し、ブラウザソースの「現在のページを再読み込み」を押します。
    • 位置や大きさが合わないときは、ブラウザソースの幅・高さをゲームの解像度にして、「変換」→「画面に合わせる」をやり直します。
    キーが効かない・キーを変えたい

    Alt+H・Alt+M・Insert は HUD が使うので、ゲームにはこの組み合わせが届きません。ほかのアプリと重なっている場合も効かないことがあります。

    変えるときは、アプリを終了してから次のファイルをメモ帳で開き、"toggleKey": "F8"（表示 ON/OFF）や "menuKey": "F9"（メニュー）のように書き足します。

    %APPDATA%\aqua-kawaii-hud-trial\settings.json
    （エクスプローラーの場所の欄に貼ると開けます）

    1時間で終了した

    体験版は 1 回の起動で 1 時間使えます。もう一度起動すれば、また 1 時間使えます。時間制限なしで使える製品版は BOOTH で販売しています。

    BAN されませんか？

    このアプリは、ゲームへのコード注入・メモリの読み書き・入力の操作をせず、画面に出ている情報に枠をつけるだけで、有利になる情報は足しません。ただし Apex Legends の非公式ツールのため、EA・Respawn による動作の保証はなく、「絶対に大丈夫」とはお約束できません。ご自身の判断でお使いください。

    「PC を保護しました」やウイルス対策ソフトの警告が出る

    個人制作でソフトに会社の署名がないため、初めて起動するときに出ることがあります。「詳細情報」→「実行」で起動できます。ダウンロードは必ず BOOTH の購入ページ（ライブラリ）から行ってください。

    設定を最初に戻したい

    アプリを終了してから、%APPDATA%\aqua-kawaii-hud-trial の中の settings.json を削除して、もう一度起動します。

    削除（アンインストール）したい
    1. アプリを終了します。
    2. 展開したフォルダごと削除します。
    3. 設定も消すときは %APPDATA%\aqua-kawaii-hud-trial を削除します。
    4. マイキャラの画像は ドキュメント\OverLIVE にあります（必要なら削除）。
    5. 診断ログは ドキュメント\OverLIVE-logs にあります（使った場合のみ）。

    Windows の設定（レジストリ）は変更していません。
