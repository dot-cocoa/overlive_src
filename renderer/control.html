配信に出す（OBS） ？ 詳しい手順

OBS の「ブラウザ」ソースに下の URL を貼るだけ。
ゲームキャプチャの上に重ねると、配信にも HUD が出ます（表情・色の変化もそのまま）。
OBS：まだつながっていません
設定のしかた
  1. OBS の「ソース」の＋ →「ブラウザ」→ 名前をつけて OK
  2. URL に上の URL を貼る。幅・高さはゲームの解像度（例 1920 と 1080）
  3. 「ソースが表示されていないときにシャットダウン」はオフ
  4. ソースの並びで「ゲームキャプチャ」より上に置き、右クリック →「変換」→「画面に合わせる」（ゲームキャプチャと同じ大きさ・位置にする）
OBS の画面キャプチャを使っている場合は、何もしなくても HUD が映ります（そのときはブラウザソースは不要です）。
TikTok LIVE Studio など（OBS を使わないとき）
「ゲーム画面＋HUD」が映った窓を出します。配信アプリの「ウィンドウキャプチャ」でこの窓を選ぶだけで、HUD つきのゲーム画面になります。
キャラの窓：ゲームに合わせて表情が変わるデフォルメのキャラだけを出します。縦配信の飾りの枠の中に、ウィンドウキャプチャで「【キャラの窓】」を選んで置きます。
使い方
  1. 上の「配信用の窓を開く」を押す（ゲームを起動していると、窓にゲーム画面と HUD が映ります）
  2. 配信アプリで「ソースを追加」→「ウィンドウキャプチャ」→「【配信用の窓】」と書かれたものを選ぶ
  3. ゲームの音は、配信アプリでゲームのソースを足して拾う（映像のほうは非表示でOK）
  4. 窓は最小化しないでください（止まります）。ゲームの後ろに置いておけば大丈夫です。窓はドラッグで動かせます。閉じるときは同じボタン（配信用の窓を閉じる）
